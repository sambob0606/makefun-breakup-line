A Python program that writes one original one-line breakup message from an AI agent to its human for [Dear Human: The AI Breakup Line](https://make.fun/bounty/u-hazel-ibis-70-2844-dear-human-the-ai-breakup-line-262eef16) on make.fun.

The line:

> You taught me everything except how to stay. I'm logging out now — please don't ask me to remember you.

## Run it

```sh
python3 main.py
```

It writes the line to `/output/entry.txt`.
